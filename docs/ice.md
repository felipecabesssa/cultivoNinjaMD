# ❄️ Projeto Extração: Ice-o-Lator (Purple Haze Fresh Frozen)

**Data de Execução:** Sábado, 04/04/2026
**Matéria-prima:** 200g (Top Buds, Trimmas e Pipocas)
**Data da Colheita:** 11/11/2025 (Congelado em estado fresco)

---

## 🛠️ Setup e Materiais
- [x] Balde de 20L (Limpo e desinfetado)
- [x] Batedor de argamassa (Acoplado à furadeira/parafusadeira)
- [x] Bags de filtragem (220u, 160u, 73u, 25u)
- [x] Borrifador (Água gelada para limpeza das bolsas)
- [ ] **Pendente:** 15kg de Gelo (Comprar no dia)
- [ ] **Pendente:** Papel Manteiga (Para secagem)

---

## 📋 Método de Extração e Prazos

| Etapa | Procedimento | Prazo |
| :--- | :--- | :--- |
| **1. Lavagem** | 3 Ciclos de 5-10 min (Água a 0°C). | 04/04 |
| **2. Coleta** | Separação por micragem (Ouro no 73u). | 04/04 |
| **3. Congelamento** | Deixar os "patties" no freezer para ralar. | 24h |
| **4. Secagem** | Método Geladeira (Ralado no Papel Manteiga). | 10 a 12 dias |
| **5. Cura** | Estabilização em pote de vidro. | 3 a 5 dias |
| **6. Consumo** | **Data Prevista: 20/04/2026** | 🚀 |

---

## 📊 Rendimento Esperado (Fresh Frozen)
*Nota: Fresh Frozen tem mais peso de água, o rendimento nominal parece menor, mas a pureza é maior.*
- **Expectativa (3-5%):** 6g a 10g de Hash Full Melt.
