# 🛡️ Protocolo de Segurança: Prevenção de Mofo (Botrytis)

Este documento descreve os procedimentos de QA para garantir a integridade das flores em períodos de alta umidade (UR > 60%).

## 🔍 Sinais Visuais de Alerta (O que procurar)
1. **Mudança de Cor Localizada:** Se uma pequena parte de um bud ficar marrom, cinza ou amarelada enquanto o resto continua verde/roxo.
2. **Folhas "Soltas" no Bud:** Se uma pequena folha que sai de dentro do bud secar sozinha e, ao puxar levemente, ela sair sem resistência.
3. **Teias ou Penugem:** Presença de uma "teia" branca ou cinza muito fina entre as cálices (parece um algodão-doce minúsculo).

## 🛠️ Procedimento de Inspeção (QA Manual)
- **Frequência:** Diária enquanto a UR estiver acima de 60%.
- **Método:** Com luvas limpas, afaste gentilmente os buds mais densos para olhar o caule interno.
- **Ferramenta:** Use uma lupa ou o zoom da câmera do celular com o LED do painel apagado.

## 🚨 Plano de Resposta a Incidentes
Caso algum sinal seja detectado:
1. **Isolamento:** Cortar a parte afetada imediatamente (sacrificar o bud para salvar a planta).
2. **Esterilização:** Limpar a tesoura com álcool 70% após cada corte.
3. **Extração:** Remover a planta do ambiente de cultivo para evitar que os esporos voem para as outras flores com o vento dos ventiladores.
