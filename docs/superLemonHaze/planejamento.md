# 🗺️ Roadmap e Milestones - Super Lemon Haze

## Objetivo do Ciclo
Desenvolver duas plantas de genética Sativa dominante com foco em extração máxima de rendimento foliar e estrutural durante o vegetativo longo.

## Milestones
- [x] **Março/Abril:** Germinação e superação de gargalo inicial.
- [x] **Maio:** Transplante para vasos definitivos (20L) e introdução de dieta mineral (Easycoco).
- [ ] **Junho:** Vegetativo Pleno. Foco em treinamento (LST/Podas) para multiplicar os topos.
- [ ] **Julho:** Transição para o quarto climatizado.
- [ ] **Agosto:** Flip para Floração (12/12) e acompanhamento do *stretch* (estirão).
